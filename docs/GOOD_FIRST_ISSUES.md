# Good-First-Issue Candidates

These are scoped candidates, not claims that contributors or issue volume already exist. Each item should be checked against the current roadmap before work begins.

- Add opt-in mirror/base-URL configuration for npm and PyPI without changing default public endpoints.
- Add more inert fixture cases for registry metadata conflicts and digest mismatch reporting.
- Improve human report wording while preserving JSON and SARIF contracts.
- Add platform-specific CLI smoke tests for the release archives.
- Add documentation examples for common SARIF consumers.
- Expand supported GitHub source URL normalization with focused offline tests.
- Add a reviewed JSON Schema artifact for report schema `1.0`.
- Improve release verification documentation after the first hosted CI run.

Each candidate needs tests, security review where inputs or trust boundaries change, and updates to the durable project documents.
