# Code of Conduct

## Our standard

We are committed to a welcoming, respectful, and constructive community. Participants must avoid harassment, discrimination, personal attacks, doxxing, threats, and knowingly misleading security claims.

## Expected behavior

Be precise, assume good intent while evaluating evidence, welcome correction, respect privacy, and focus criticism on ideas and code. Security reports should follow SECURITY.md.

## Enforcement

Project maintainers may remove comments, close discussions, or restrict participation when behavior violates this code. Report conduct concerns privately to the project maintainer until a dedicated contact is configured.
