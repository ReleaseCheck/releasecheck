# Support

ReleaseCheck is an open-source project in post-Phase-14 audit, pre-v0.1 release state. Hosted CI and the final release decision are still pending.

For usage questions, first read README.md, PROJECT_CONTEXT.md, ROADMAP.md, docs/USAGE.md, docs/REPORTS.md, and docs/DESIGN.md. For reproducible bugs, include the ReleaseCheck version or commit, operating system, command, sanitized input, expected result, actual result, and test output. For current release limitations, read FINAL_AUDIT.md.

Do not include secrets, private package data, or executable artifacts in public reports. Suspected vulnerabilities should follow SECURITY.md instead of public issue discussion.
