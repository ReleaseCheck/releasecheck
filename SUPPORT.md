# Support

ReleaseCheck is an open-source project in active bootstrap and v0.1 development.

For usage questions, first read README.md, PROJECT_CONTEXT.md, ROADMAP.md, and docs/DESIGN.md. For reproducible bugs, include the ReleaseCheck version or commit, operating system, command, sanitized input, expected result, actual result, and test output.

Do not include secrets, private package data, or executable artifacts in public reports. Suspected vulnerabilities should follow SECURITY.md instead of public issue discussion.
