# Offline Fixtures

These fixtures are inert inputs for deterministic tests. They are never
installed, imported, executed, or passed to a package manager.

The repository-wide matrix in `tests/fixture_matrix_test.go` covers:

1. matching source and artifact inventories;
2. artifact-only files;
3. source-only files;
4. modified files;
5. malformed archives;
6. install-time metadata;
7. missing repository metadata;
8. unavailable source references;
9. unsafe archive paths;
10. symlink edge cases;
11. large-file/archive limits; and
12. provenance availability and validity variations.

Archive bytes are generated by deterministic standard-library helpers inside
the offline test matrix so binary fixtures do not depend on platform-specific
metadata or external tools. Registry tests use local HTTPS test servers only;
there are no live-registry tests in the default suite.
